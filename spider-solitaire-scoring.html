How SpiderImp scoring works

SpiderImp does not use the old desktop “start at 500 and subtract” point total. A win is clearing eight same-suit King-to-Ace runs. Rankings are fewest moves first, then fastest time.

What counts as a win?

Moving all eight completed same-suit sequences to the Completed area. There is no partial “points for foundation” layer on this site.

How are Best Scores ordered?

  1. Moves — lower is better.
  2. Time — used when move counts tie.

Each difficulty (1, 2, and 4 suits) has its own board. Switching modes does not mix them.

What about Daily Challenge?

Daily keeps a personal best for that calendar day and mode on your device. Restart still uses today’s shared deal. Tomorrow’s seed is new. See Daily Challenge.

Where is the data stored?

Best Scores, Statistics, Daily bests, volume, and resume state live in browser local storage for spiderimp.com. There is no SpiderImp account and no cloud sync. Clearing site data deletes the record. Copy Score after a win if you want to paste the result elsewhere.

How is this different from Windows Spider?

Many desktop versions subtract points for time or moves from a starting total. SpiderImp’s leaderboards are simply efficiency (moves) then speed, which matches a “fewest moves” practice goal. Strategy that reduces extra deals and undo-loops will climb the local board: strategy tips.
