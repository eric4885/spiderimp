Windows Spider Solitaire online

SpiderImp mirrors the classic Windows Spider Solitaire feel: two decks, ten columns, 1 / 2 / 4 suits, deal from stock when columns are full, and eight King-to-Ace same-suit clears—free in the browser.

Is this like Microsoft Spider Solitaire?

Same core rules Microsoft popularized: 104 cards, ten columns, empty-column deal lock, same-suit group moves. SpiderImp adds Daily Challenge, undo, hint, and move/time scoring stored locally—no Microsoft account.

Scoring difference

Old Windows builds used subtractive points. SpiderImp ranks fewest moves, then fastest time. Details: scoring guide.

Which suit count matches Windows?

  • 1 suit — easiest (Beginner on Windows)
  • 2 suits — intermediate; our recommended default
  • 4 suits — expert / classic hard
