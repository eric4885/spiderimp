How to get Spider Solitaire back on Windows 11

If Microsoft Spider Solitaire is missing from your PC—or you do not want the Microsoft Store version—open SpiderImp in Chrome or Edge. Play the classic Windows Spider Solitaire rules free in the browser: two decks, ten columns, 1 / 2 / 4 suits, no download and no Microsoft account.

Why did Spider Solitaire disappear on Windows?

Windows 10 and 11 no longer ship the old desktop Solitaire collection by default. Many players search "how do I get my Spider Solitaire back" after an upgrade or a clean install. You can install Microsoft's Solitaire & Casual Games from the Store, or skip the install and play in the tab at spiderimp.com.

Browser play vs Microsoft Store

  • SpiderImp (browser) — instant play, no download, works on Windows 11, 10, and older PCs with a modern browser.
  • Microsoft Store app — separate install, ads in the free tier, Microsoft account optional.

If you want the feel of classic windows spider solitaire without hunting for the old .exe, SpiderImp mirrors the same tableau rules. Recommended mode: 2 suits (everyday) or 1 suit to learn.

Is this like Microsoft Spider Solitaire?

Same core rules Microsoft popularized: 104 cards, ten columns, empty-column deal lock, same-suit group moves. SpiderImp adds Daily Challenge, undo, hint, and move/time scoring stored locally—no Microsoft account.

Scoring difference

Old Windows builds used subtractive points. SpiderImp ranks fewest moves, then fastest time. Details: scoring guide.

Which suit count matches Windows?

  • 1 suit — easiest (Beginner on Windows)
  • 2 suits — intermediate; our recommended default
  • 4 suits — expert / classic hard
